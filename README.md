# Strada — персональный сайт

Статический сайт без установки зависимостей.

## Запуск
`npm run dev`, затем открыть http://localhost:4173. Для доступа только с этого компьютера: `python3 -m http.server 4173 --bind 127.0.0.1 --directory public`.

## Публикация
`npm run build` создаёт `dist/`. Загрузите содержимое этой папки на любой статический хостинг. Сайт в текущем состоянии не опубликован.

## Редактирование
- Тексты, услуги, цены, ссылки: `public/index.html`.
- Цвета, шрифты и адаптивность: `public/style.css`.
- Фотографии: `public/images/`. Оптимизированные JPEG получены из оригиналов в `assets/img/`.
- Дипломы: добавьте реальные файлы в `public/documents/` и записи в массив `documents` в `public/app.js`. Просмотр с увеличением уже предусмотрен.
- Иконка сайта: `public/favicon.svg`.

## Перед публикацией
Добавить настоящие дипломы и утвердить правовые тексты `privacy.html` и `consent.html`: сейчас это информационные страницы о текущем способе обращения, не готовые юридические документы. Форм сбора данных и аналитики нет. Google Fonts требует интернет-соединения; для автономной публикации шрифты следует разместить локально. Уточнить актуальность квалификаций и цен у владельца.
